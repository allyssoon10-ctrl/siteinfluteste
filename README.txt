PRISCILA SIMOES | VIDA REAL NOS EUA

Site responsivo para desktop, tablet e celular.

ARQUIVOS
- index.html: estrutura e conteúdo da página
- styles.css: identidade visual e regras responsivas
- script.js: menu mobile e ano automático do rodapé
- assets/foto-familia.jpg: fotografia enviada para o hero
- assets/: imagens de referência e prévias do projeto

COMO VISUALIZAR
Abra index.html em um navegador. Para testar o mobile, use as ferramentas de desenvolvedor do navegador ou abra o site em um celular.

COMO PUBLICAR NO GITHUB PAGES
1. Envie index.html, styles.css, script.js e a pasta assets para a raiz do repositório.
2. No GitHub, abra Settings > Pages.
3. Em Build and deployment, selecione Deploy from a branch.
4. Selecione a branch main e a pasta /(root), depois salve.

O site usa links públicos do Instagram e Google Fonts. A fotografia principal é local e acompanha o projeto.
